# Ember Phnom Penh

A zero-build scented candle website made with HTML, CSS, Bootstrap, and JavaScript.

## Pages

- `index.html` — Home
- `shop.html` — Shop
- `about.html` — About and contact
- `tips.html` — Candle tips
- `login.html` — Sign in
- `signup.html` — Account creation
- `cart.html` — Local shopping cart
- `checkout.html` — Checkout and order confirmation

Open `index.html` directly in a browser. There is nothing to install and no
build command.

There is no database, API, server framework, package manager, or back-end
dependency.
